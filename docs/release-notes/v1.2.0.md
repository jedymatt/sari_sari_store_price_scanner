## What shipped

- **Mga Utang** - per-customer credit ledger. Customers (name, optional phone), debt
  (utang) and payment (bayad) entries with notes and dates, running balance per
  customer, total outstanding across all customers, and customer search. (#15, #17)
- **Trash** - customers are soft-deleted instead of removed. Restore them, or let them
  auto-purge 30 days after being trashed.
- Cebuano translations for every new string.
- Android toolchain upgrade and AGP built-in Kotlin. (#19, #21)
- App settings moved to an `InheritedWidget` instead of `findAncestorStateOfType`. (#19)

## Before uploading

- Run `flutter test` and `flutter analyze`, and make sure both are clean.
- Build the bundle: `flutter build appbundle --release`.
- Check the Play Console: version code must be higher than anything already uploaded.
  `+4` and `+5` were bumped in git but may never have been shipped, so confirm what the
  console actually has.
